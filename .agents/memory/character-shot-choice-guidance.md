description: Keep character profile shot recommendations useful without repeating them across every section.

For WTSL Forum character profiles, include shot-choice suggestions sparingly in a few relevant places; do not repeat them throughout summaries, comparisons, and every guidance card.

**Why:** The user clarified that shot-choice suggestions should be sprinkled in, not removed entirely or allowed to oversaturate profiles.

**How to apply:** Use concise, character-specific cues only where the character's ratings and official TE4 manual support the choice. Treat narrow model estimates (such as a shoulder-height fit) as that scenario only; never turn them into universal advice or repeat the same incoming-ball case across multiple cards. Describe stroke hand use in plain language (for example, “one-handed forehand”), not jargon-only setup labels. Keep general summaries objective, filter unsupported tactical copy, and avoid repeated game plans.
