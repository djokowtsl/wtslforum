---
name: Character shot-choice guidance
description: Keep character profile shot recommendations useful without repeating them across every section.
---

For WTSL Forum character profiles, keep the copy concise and conversational. State the useful character detail directly; do not repeatedly explain that claims come from WTSL or the TE4 manual. Keep source attribution in one compact reference, not in the summary and every guidance card. Include shot-choice suggestions sparingly in a few relevant places rather than throughout summaries, comparisons, and every guidance card.

**Why:** The user said the source-heavy copy reads like an encyclopedia and preferred the earlier cadence. They also clarified that average maximal serve speed and average first-serve percentage are separate metrics.

**How to apply:** Write summaries as natural descriptions of the character’s strengths without source or methodology caveats. Keep one concise TE4 reference near the mechanics section; avoid repeating “WTSL” or “the manual says” in profile copy. Preserve useful numbers and short, conditional shot cues. Label average maximal serve speed explicitly as a speed in km/h, and never conflate it with an average first-serve percentage estimate. Use the manual’s equal-rating success anchors (Strong 70%, Normal 85%, Safe 100%); when Power and Consistency differ, state only the supported direction for Strong and keep Normal between Strong and Safe unless an exact rate is documented. Keep Precision as a placement cue unless a source verifies a success-rate effect. Treat narrow model estimates (such as a shoulder-height fit) as that scenario only; never turn them into universal advice or repeat the same incoming-ball case across multiple cards. In Shot Variety, prioritize Drop Shot and Slice Mastery; only discuss Lob when it stands out on the roster. Banana-shot, short-slice, and defensive-slice recommendations must remain conditional profile heuristics, not claims guaranteed by the manual. Describe stroke hand use in plain language (for example, “one-handed forehand”), not jargon-only setup labels. Filter unsupported tactical copy and avoid repeated game plans.
