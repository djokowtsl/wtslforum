# Continuous player body

Innerscene, “Human base mesh with editable 53-bone rig”.
https://www.innerscene.com/tools/library/3d-parts/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1

CC0 public-domain dedication, based on MakeHuman/MPFB assets.
https://creativecommons.org/publicdomain/zero/1.0/

The web asset is simplified to 20,000 triangles, retaining the complete native
body, wrists, hands, finger joints, and skin weights. WTSL adds skinned tennis
garments, generic material colours, authored finger closure, and procedural
DMO-target retargeting. It is a generic player, not a real-player likeness.

No Tennis-MoCap BVH recording is bundled or used by this production renderer.
