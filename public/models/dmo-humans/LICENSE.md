# CC0 human character assets

Male and female base characters by **Grab3D**, licensed **CC0-1.0**.

- https://grab3d.com/models/characters/man-base-character/
- https://grab3d.com/models/characters/woman-base-character/
- https://grab3d.com/license/
- https://creativecommons.org/publicdomain/zero/1.0/

The source assets expressly permit use, modification and redistribution.
These are generic synthetic human characters, not representations of WTSL members.

WTSL adaptations: web mesh simplification, resized PBR texture maps, runtime
tennis-kit colouring, DMO skeletal retargeting and separate tennis footwear.
No canned walk/run animation determines the recorded match positions.

`provenance.json` records the original download URLs, source hashes and output
budgets. `tools/prepareDmoHumanModels.mjs` reproduces these small web assets.
The full-size source downloads are intentionally excluded from the repository.
